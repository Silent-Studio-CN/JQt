# JQt v0.7.0-Universal-Kit — 跨平台独家能力包

> Exclusive Kit 从 Windows 扩展到 macOS / Linux：**同一 API，三平台同语义，不区别对待**。

## 跨平台统一 API（3 平台同签名）

| API | Windows | macOS | Linux |
|-----|---------|-------|-------|
| `QApplication.preventSleep(boolean)` | SetThreadExecutionState（阻止睡眠+关屏） | NSProcessInfo idleSystemSleepDisabled | D-Bus ScreenSaver / gnome-SessionManager Inhibit |
| `QApplication.setAutoStart(enable, path)` | HKCU Run 注册表 | LaunchAgent plist | XDG autostart .desktop |
| `QApplication.showNotification(title, body, ms)` | 托盘气泡 | NSUserNotification（通知中心） | D-Bus org.freedesktop.Notifications |

## macOS 独家（对齐 Windows 任务栏进度 / DWM 能力）

- **Dock 角标** — `QMainWindow.setDockBadge("5")` / `clearDockBadge()`（NSDockTile，未读角标）
- **透明标题栏** — `setMacTitlebarTransparent(true)`：保留红黄绿按钮 + 内容上延（Qt 官方只能全有或全无）
- **全尺寸内容视图** — `setMacFullSizeContentView(true)`：沉浸式布局

## 构建与验证

- build-linux.sh 增加 QtDBus 链接；build-macos.sh 链接 AppKit/Foundation/CoreFoundation
- CI 三平台冒烟新增 SmokeExclusive（新 API 全量调用验证）
- 双 Qt（6.8.3 + 6.11.2）× Linux x64 / Windows x64 / Windows ARM64 / macOS x64 全绿

## 已知限制

- Linux 全局热键（X11 XGrabKey / Wayland portal）依赖 libX11 且 Wayland 受限 → v0.7.x 候选
- macOS 通知用 NSUserNotification（Apple 弃用但可用，无需权限弹窗）；Windows 通知为托盘气泡（Toast 需打包身份）
- macOS 标题栏 API 建议在 show() 前调用
