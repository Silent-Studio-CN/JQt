# JQt v0.6.1-Exclusive-Kit

Windows 独家能力包（2026-08-28）——Qt 官方未封装的系统能力，JQt 首次 API 化。
Windows Exclusive Kit - APIs Qt never wrapped.

## 独家能力

- **原生边框颜色**：setNativeBorderColor(0xAARRGGBB)（Win11 22H2+ DWM）
- **原生标题栏颜色**：setNativeCaptionColor + setNativeCaptionTextColor（Win11 22H2+）
- **深色标题栏**：setNativeDarkTitleBar(true)（Win10 1809+）
- **Mica 背景**：setMicaBackground(true)（Win11 22H2+ 原生材质）
- **任务栏进度**：setTaskbarProgress(value, max)（Win10+ ITaskbarList3）
- **全局热键**：GlobalHotkey.register("Ctrl+Shift+X", handler)（应用失焦也生效）
- **开机自启**：QApplication.setAutoStart(true, exePath)（HKCU Run）

旧系统调用静默忽略（不报错不崩溃）。

## 规模

- API ~480 方法 / 48 类；双 Qt（6.8.3 LTS + 6.11.2）× Windows x64/ARM64 CI 全绿

## 资产 · Assets

- jqt-0.6.1-Exclusive-Kit.jar
