# JQt v0.7.2-Universal-Kit — 工业模块：QPrinter + QSql

> QtPrintSupport / Qt6Sql 首次 API 化（均为 qtbase 模块）。

## QPrinter（打印 / PDF）

- `QPrinter` 类：setOutputFormat(NATIVE/PDF)、setOutputFileName、setResolution、setPageSize(A4/A3/A5/Letter/Legal)、newPage
- **`QTextEdit.print(QPrinter)` / `printToPdf(path)`** — 解锁 L1 阻塞项 qplaintextedit::print
- **`QWidget.printToPdf(path)`** — 任意控件渲染导出 PDF

## QSql（数据库）

- `QSqlDatabase`：addDatabase(SQLITE/PSQL/MYSQL)、setDatabaseName/UserName/Password/HostName/Port、open/close/isOpen/exec/lastError
- `QSqlQuery`：next/value/valueCount/isSelect/numRowsAffected/lastError
- **Windows 驱动插件 workaround**：QFactoryLoader 不搜索 PATH → QPluginLoader 预加载 + registerSqlDriver（Qt 公开 API），SQLite 开箱即用
- **可用性预检**：驱动不可用时不再创建无效连接（修复 Linux/macOS 退出时 SIGSEGV）
- 发布包含 plugins/sqldrivers/qsqlite.dll

## 验证

- SmokeV072（PDF×3 + SQLite 增删查）接入四平台 CI（Win x64/ARM64、Linux、macOS × Qt 6.8.3/6.11.2）**全绿**
- Linux CI 启用系统 libqt6sql6-sqlite

## 资产

- `jqt-0.7.2-Universal-Kit.jar` — Java API（全平台）
- `jqt-0.7.2-Universal-Kit-windows-x64.zip` — Windows x64 完整包（Qt 6.11.2 运行库 + 文档 + SQL 驱动）
- 裸库：`jqt-windows-6.8.3/6.11.2.dll`、`jqt-windows-arm64-*`、`libjqt-linux-6.8.3/6.11.2.so`、`libjqt-macos-6.8.3/6.11.2.dylib`
