# JQt v0.5.0-TEST

版本命名规则更新：后缀从 `-alpha` 改为 `-TEST`（x.x.x-TEST）。
Version suffix scheme updated: `-alpha` → `-TEST` (x.x.x-TEST).

## 批 1 控件海啸 · Widget wave

- 对话框家族 · Dialogs: `QInputDialog` (`getText`/`getInt`/`getItem`) · `QFileDialog` (`getOpenFileName`/`getSaveFileName`/`getExistingDirectory`) · `QColorDialog` (`getColor` 0xAARRGGBB) · `QFontDialog` (`getFont` "Family,size") · `QMessageBox` 增强 (`showWarning`/`showCritical`/`showOkCancel`)
- 数据表格/树 · Data: `QTableWidget` (单元格/表头/行列/跨列/点击信号) · `QTreeWidget` (itemId 节点体系/父子/展开折叠)
- 选项卡/分组/分割 · Tabs & groups: `QTabWidget` · `QGroupBox` · `QStackedLayout` · `QSplitter`
- 输入控件 · Input: `QSpinBox` · `QDial` · `QRadioButton` · `QDateTimeEdit`
- 布局升级 · Layout: `QGridLayout` (跨行跨列/拉伸) · `QFormLayout`

## 批 2 窗口体系 · Window family

- `QMenu` (actionId 触发) · `QToolBar` · `QStatusBar` · `QSystemTrayIcon` (气泡消息)
- `QTextEdit` 富文本编辑

## 批 3 渲染适配 · Rendering

- `QApplication.rhiBackend()` + `--rhi` (d3d11 默认 / software 兜底)
- 实测：QSG_RHI_BACKEND 仅影响 Qt Quick；QWidget 在 Windows 固定 D3D11（opengl/vulkan 请求回退 d3d11，已在 API 文档注明）

## 批 4 能力 · Capability

- `QCanvasWidget` + `QPainter` 自绘画布（12 个 2D API：线/矩形/圆/圆角/文本/字体/变换）
- `QApplication.runOnUiThread()` 后台线程安全回 UI

## 批 5 稳定性 · Stability

- Windows SEH 崩溃日志（jqt-crash.log：时间/异常码/地址/线程）

## 规模 · Scale

- API: ~220 → 324 方法；类: 24 → 47
- 双 Qt（6.8.3 LTS + 6.11.2）× Windows x64/ARM64 CI 全绿

## 修复 · Fixes

- QTimer::singleShot 缺 context 导致跨线程 schedule 永不执行
