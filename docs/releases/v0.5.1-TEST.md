# JQt v0.5.1-TEST

启动体验修复 + 主题健壮性（2026-08-27）。Startup polish + theme robustness.

## 修复 · Fixes

- **启动窗口闪现**（污点消除）：布局未安装时 addWidget 不再 show——控件不会成为顶层窗口闪现；子控件由父窗口 setLayout 递归显示（QStackedLayout 页跳过，防多页堆叠）。启动窗口峰值 10-15 → **1**
- **窗口尺寸被布局 sizeHint 撑大**（16:9 破坏）：面板级 setLayout 不再触发子控件显示，窗口保持构造尺寸（1280x720 实测）
- **QApplication.setTheme 主题模板缺失崩溃**：降级为警告 + 默认配色（Qt 一致行为），应用不再因 themes 缺失而崩溃
- **jpackage 分发**：runtime/bin/java.exe 为必需文件；themes/ 目录需随包分发

## 验证 · Verified

- 启动窗口峰值：10-15 → 1
- JQtGallery 1280x720（16:9）保持
- 无 themes 目录不崩溃（降级验证）
- FluentDemo / QfDemo / JQtDemo 回归全绿

## 资产 · Assets

- jqt-0.5.1-TEST.jar（Java API）
- jqt-0.5.1-TEST-windows-x64.zip（jar + jqt.dll + Qt 6.11.2 运行时）
