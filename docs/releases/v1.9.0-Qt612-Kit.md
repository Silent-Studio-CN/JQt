# JQt v1.9.0-Qt612-Kit — 跟进 Qt 6.12.0 LTS

**发布于**：2026-10-02 · 主题：**把 Qt 版本线拉到最新(6.12.0 LTS)并补齐 CI 矩阵缺口**。

## 亮点

| 项目 | 说明 |
|---|---|
| **Qt 6.12.0 支持** | MinGW 13.1 工具链不变；JNI 桥与 Java 层**零改动**通过编译 |
| **双版本线** | 6.12.0(最新) + 6.8.3 LTS(长期) 并行构建与冒烟 |
| **Windows x64 补齐** | 此前该作业只产出 6.8.3 dll(发布时 6.11.2 x64 裸库需本地补产)；现在一次产出两个版本 |
| **CI 4 平台 × 2 版本** | Linux x64 / Windows x64 / Windows ARM64 / macOS x64 |
| **qtserialport 提速** | Linux 侧由"源码 cmake 编译"改为官方 prebuilt addon |

## 兼容性

- **源码兼容**:从 1.8.0 升级无需改代码(API 未删减,仅新增 Qt 版本支持)
- **运行期**:同一份 jar 可分别配 6.12.0 / 6.8.3 的裸库运行
- **工具链**:MinGW-w64 13.1.0(与 Qt 6.12.0 官方 SDK 一致)

## 已知事项

- macOS 的 6.12.0 走手动 7z 安装:aqtinstall 3.3 尚不能解析 Qt 新仓库(6.11+)的版本元数据
- Maven Central 仍未发布 1.8.0/1.9.0 线(当前 Central 为 0.7.5),JitPack 按 tag 构建
