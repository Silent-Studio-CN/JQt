# JQt v0.7.4-Universal-Kit — QSerialPort 完整绑定（工业串口）

> **版本命名**：`0.7.4` 是版本号，`-Universal-Kit` 是发布代号（三平台同能力），
> 内容即完整版。Maven Central 上发布为 `io.github.silent-xiaomiao:jqt:0.7.4`（数字版本，无代号后缀）；
> JitPack 为 `com.github.Silent-Studio-CN:JQt:0.7.4-Universal-Kit`。三个渠道同一份代码、同一份产物。

> Qt SerialPort 模块完整 API 化（独立模块，CI 四平台安装依赖）。

## QSerialPort

- **端口枚举**：`availablePorts()`（QSerialPortInfo）
- **配置**：`setPortName` `setBaudRate` `setDataBits` `setParity` `setStopBits` `setFlowControl`（Qt 枚举一一对应）
- **打开/关闭**：`open(READ/WRITE/READ_WRITE)` `close` `isOpen`
- **读写**：`write(byte[]/String)` `readAll` `readAllText` `readLine` `bytesAvailable` `waitForReadyRead(ms)` `flush` `clear`
- **错误**：`errorString()`
- **信号**：`onReadyRead`（数据到达）/ `onBytesWritten`（写入完成）

## 构建（qtserialport 为独立 Qt 模块）

- **本机**：源码编译安装（CMake + windres 显式指定解决 MinGW RC 反斜杠路径问题；qmake 已从 Qt 6 移除）
- **CI**：Windows aqt `-m qtserialport` / Linux 源码编译 ×2 版本 / macOS aqt `-m qtserialport` / ARM64 官方 7z ×2 版本
- 发布包含 Qt6SerialPort 运行库

## 排障记录（跨平台 include 守卫陷阱）

QSerialPort 头曾被 GL 平台守卫（`#if (defined(_WIN32) && !defined(_M_ARM64)) || defined(__linux__)`）误包住，导致 macOS/ARM64 上 include 被跳过（类型未声明而非 file-not-found，排查多轮）——已移到守卫外。macOS framework 头含 fake-header 的扁平布局由 build-macos.sh 复制到标准模块布局解决。

## 验证

- SmokeV074（端口枚举真实返回 4 个 COM 口 + 全配置 + 无设备 open 失败不崩）四平台 CI 全绿
