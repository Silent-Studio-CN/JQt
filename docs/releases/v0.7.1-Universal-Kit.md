# JQt v0.7.1-Universal-Kit — L1 收尾：190/205（92.7%）

> L1 常用 API 从 149 补到 190/205；剩余 15 项为 ⛔ 阻塞归档（model/validator/pixmap 对象化依赖、Qt 6 不存在的 API）。

## 新类（4 个）

- **QAction** — text/icon/shortcut/toolTip/font/checkable/toggle/triggered/toggled/trigger/setMenu
- **QDialog** — exec（模态）/open（非模态）/accept/reject
- **QMenuBar** — addMenu(String/QMenu)/clear/triggered
- **QListView** — QStringListModel 内部实现：addItem/setItems/item/count/clear/setSpacing/setWordWrap/currentItem/setCurrentItem/selectionChanged

## 关键补全

- **QMessageBox 实例化**（setText/setWindowTitle/setIcon/exec/open/close；静态 show* 保留）
- **QFile 实例 API**（open READ/WRITE/APPEND、close、isOpen、write、readAll、readLine）
- **QClipboard 图像**（setPixmap(byte[] PNG/JPEG) / pixmap()）
- **QTextEdit 底层改 QPlainTextEdit**（placeholderText、纯文本语义）
- **QPushButton** text/icon/shortcut；**QMenu** icon；**QListWidget** itemChanged/row
- **QWidget** find(winId)/layout()/setWindowIcon；**QColorDialog** open+colorSelected（非阻塞）
- **QColor** 值类（HSV value/hue/saturation）；**QApplication** paletteText/palettePlaceholderText
- QSize width()/height()、QLineEdit/QTextEdit placeholderText getter

## 验证

- 新增 SmokeL1 / SmokeL1b2 冒烟，接入四平台 CI（Windows x64/ARM64、Linux、macOS × Qt 6.8.3/6.11.2）全绿
