## 主题

## L1（手写收官，178/178）

- 语义短名（setTitle/title、QMessageBox Qt 名静态工厂）；setParent/setAttribute、按钮状态、setPixmap、
  行编辑选区、下拉 item/currentData、布局 insertWidget/setStretch/stretch、对话框 done/result/信号、
  列表行语义、消息框标准按钮
- **QMainWindow 主窗口语义（壳内组装）**：centralWidget/menuBar/statusBar/toolBar/dock 全家 +
  nativeSetLayoutForce；遗留 addWidget/setLayout 用法零回归

## L2（B1-B10 + 功能层冲刺）

- 状态持久化：QSplitter、QMainWindow 壳结构（objectName 匹配、原子恢复）
- 控件各族：按钮自动重复/动画点击/互斥、标签文本格式与旗标、行编辑光标/掩码/边距、下拉查找/策略/数据层、
  列表行语义、应用查询族、布局方向/支柱/网格几何、窗口旗标/输入法提示/焦点链
- **validator 对象体系**：QValidator + 整数/浮点/正则三实现 + 控件接线
- **分组门面**：window()/style()/drag()/focus()/event()/nativeApi()（native 为 Java 关键字故命名 nativeApi）
- 汇总冒烟 SmokeL2b1（25）+ SmokeL2b2（34）入库
