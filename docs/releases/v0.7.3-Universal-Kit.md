# JQt v0.7.3-Universal-Kit — QOpenGLWidget 绑定（GPU 渲染画布）

> Qt6OpenGLWidgets 首次 API 化——补上 JQt 的 GPU 渲染缺口（此前仅 QPainter 软件光栅化）。

## QOpenGLWidget

通用 GL 画布（Qt Widgets 标准控件），生命周期回调与 Qt 一一对应：

- `onInitialize(Runnable)` — initializeGL（GL 首次可用，查版本/上传纹理）
- `onPaint(Runnable)` — paintGL（每次重绘，**执行时 GL context 已 current**）
- `onResized(w, h)` — resizeGL（更新 glViewport/投影）
- `setClearColor(0xAARRGGBB)` + `setAutoClear(boolean)`（默认自动清屏，可关）
- `makeCurrent()` / `doneCurrent()`（GUI 线程外初始化 GL 资源）

## LWJGL 挂接（Minecraft 同款方案）

paintGL 回调内 GL context 已 current → Java 侧 `GL.createCapabilities()` 直接可用。
**JQt 提供画布与 context，GL 调用交给 Java 生态标准（LWJGL）**——2D 加速 / 图像视频帧 / 图表 / 3D 可视化（JME/LWJGL 集成路径）通用。

## 平台说明

- Windows x64 / Linux：完整支持（本机真实窗口实测回调触发 init=1/paint=4/resize=1）
- **macOS / Windows ARM64**：Qt 官方构建不含 OpenGLWidgets 模块（Apple 弃用 OpenGL）→ 构造抛 `UnsupportedOperationException`，API 存在但平台降级
- GL 函数经 QOpenGLFunctions 运行时解析（不直接链接）

## 验证

- SmokeV073 四平台 CI（offscreen 容错；ARM64/macOS 自动 SKIP）
- 构建：三平台脚本加 Qt6OpenGLWidgets/Qt6OpenGL（qtbase 模块，CI 零新依赖）
